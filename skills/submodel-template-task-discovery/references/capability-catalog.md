# Capability Catalog for Submodel Template Programs

## Core capabilities

1. **template-quality-gate**
   - Enforce pass/fail checks before merge or release.
2. **template-diff-risk-analysis**
   - Assess breaking-change risk between template revisions.
3. **template-migration-assistant**
   - Suggest mechanical migration steps for changed structures.
4. **template-example-synthesizer**
   - Generate valid and invalid JSON examples for tests.
5. **template-governance-auditor**
   - Verify naming policies, semantic reference policies, and documentation completeness.

## Supporting capabilities

6. **template-ci-wiring**
   - Integrate checks into CI workflows.
7. **template-release-readiness**
   - Produce a release decision report from validation evidence.
8. **template-error-taxonomy**
   - Maintain stable, reusable error codes and remediation guidance.

## Suggested trigger phrases

- "check conformance"
- "prepare template for review"
- "find missing quality tasks"
- "assess change impact"
- "build release gate"
