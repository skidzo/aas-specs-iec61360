# Skill Sets for JSON-Oriented Submodel Template Work

This folder contains reusable skill sets for agentic interactions with **Claude Sonnet** and **Claude Haiku**.

Focus area:
- Submodel template processing
- JSON-first workflows
- Conformance checks against IEC 61360 data specification context

## Available skill sets

1. `submodel-template-conformance`
   - Validate JSON submodel templates for structural and semantic conformance.
2. `submodel-template-json-transformation`
   - Normalize and transform JSON templates into stable, reviewable artifacts.
3. `submodel-template-task-discovery`
   - Discover additional relevant tasks, risks, and capability gaps around template quality.

## Repository context used

- Spec identity: `IDTA-01003-a`
- Scope: Part 3a, Data Specification IEC61360
- Version context: `v3.1.1`
